# Python Student Helper

## About the Project
Python Student Helper is a beginner-friendly Python project designed to help students with study tips, Python practice, and motivation.

## Features
- Enter student name
- Study tips
- Python practice suggestions
- Motivational messages
- Interactive menu

## Technology Used
- Python

## How to Run
1. Download the student_helper.py file.
2. Open it using Python.
3. Run the program.
